# Oppgave 04 — Planet Code Archive

**Hovedfokus:** arrays

Du har et fast arkiv av planetkoder.

Oppgaver:
1. Skriv antall elementer med `.Length`.
2. Skriv første og siste kode ved indeks.
3. Bruk en løkke til å finne om `"KAPPA-9"` finnes.
4. Lagre resultatet i `found`.

Ikke bruk LINQ eller `Array.IndexOf`.

## Kjøring

```bash
dotnet run
```
