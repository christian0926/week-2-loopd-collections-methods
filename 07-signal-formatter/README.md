# Oppgave 07 — Signal Formatter

**Hovedfokus:** metodeparameter og returverdi

Lag metoden:

```csharp
static string FormatSignal(string source)
```

Den skal returnere teksten i dette formatet:

```text
[SIGNAL FROM: MOON-BASE]
```

Krav:
- Metoden skal **returnere** stringen, ikke skrive den direkte.
- `Main`/top-level-koden skal kalle metoden minst tre ganger med ulike verdier og skrive returverdien.
- Gjør kilden uppercase med `.ToUpper()`.

## Kjøring

```bash
dotnet run
```
