# Oppgave 05 — Crew Queue

**Hovedfokus:** List<T>, Add, Remove og Count

En transportkø endrer seg mens programmet kjører.

Start med listen i `Program.cs` og gjør dette i rekkefølge:
1. Legg til `"Mira"` og `"Sol"`.
2. Fjern `"Bex"`.
3. Skriv antall personer med `.Count`.
4. Iterer over den ferdige listen og skriv alle navn.

Bruk `List<string>`, `Add`, `Remove` og `Count`.

## Kjøring

```bash
dotnet run
```
