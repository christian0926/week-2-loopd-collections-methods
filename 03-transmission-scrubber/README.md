# Oppgave 03 — Transmission Scrubber

**Hovedfokus:** for-løkke og string-indeksering

En overføring skal undersøkes tegn for tegn ved hjelp av indeks.

Bruk en vanlig `for`-løkke fra `0` til `transmission.Length - 1`.

Finn:
- hvor mange `?` som finnes
- indeksene der `?` forekommer

Eksempel: `"AX?19??Q"` har markører på indeks `2`, `5`, `6`.

Ikke bruk `foreach` i denne oppgaven.

## Kjøring

```bash
dotnet run
```
